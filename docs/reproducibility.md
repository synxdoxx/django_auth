# Протокол проверки воспроизводимости (СРС №8)

Этот документ — **шаблон для фактической проверки**, а не утверждение о выполненных испытаниях. Для достоверного отчёта повторите запуск в новом виртуальном окружении/копии репозитория, запишите результат и приложите собственные скриншоты.

| № | Проверка | Команда / способ | Фактический результат |
|---|---|---|---|
| 1 | Установка зависимостей | `python -m pip install -r requirements.txt` | Не проверено; приложить скриншот |
| 2 | Конфигурация без секретов из кода | Задать переменные из `deployment.md` | Не проверено; `.env.example` исходно пуст |
| 3 | Миграции | `python manage.py migrate` | Не проверено; приложить вывод |
| 4 | Интерфейс и стили | `/`, `/labs/`, `/profile/` | Не проверено; скриншот страницы |
| 5 | GET и изменение API | GET `/api/tickets/`, POST `/api/tickets/` с CSRF | Не проверено; скриншоты Network без cookie |
| 6 | Сохранение данных | Создать тестовую заявку, перезапустить, повторить GET | Не проверено |
| 7 | Ошибка и устранение | Например, временно не задавать `DJANGO_SECRET_KEY`, затем задать | Не проверено; сохранить симптом и решение |

## Что приложить в отчёт
1. Ссылку на репозиторий или архив с документацией.
2. Перечень файлов `README.md`, `docs/*.md` и их назначение.
3. Диаграммы из `architecture.md` и `database.md` (при необходимости отобразить Mermaid и сделать скриншот).
4. Фрагмент README и карточки **двух разных** API-операций, например `POST /api/tickets/` и `POST /api/submissions/{id}/book/`.
5. Заполненную таблицу выше с реальными результатами.
6. Один действительно возникший сбой: симптом → диагностика → исправление → повторная проверка.
7. Скриншоты установки, миграций, UI, GET и POST/PATCH в Network без секретов.
8. Краткий вывод о шагах, которые пришлось добавить в руководство после повторного запуска.

## Выявленные при анализе архива ограничения
- `.env.example` пустой; переменные задокументированы в `deployment.md`, но исходный файл не менялся.
- `build.sh` пустой; рабочие команды Render описаны отдельно.
- `.env` автоматически не загружается в `settings.py`; для локального запуска нужен `export` или настройка IDE.

**Заключение после практической проверки:** заполнить только по итогам собственного запуска. До выполнения испытания нельзя утверждать, что воспроизводимость подтверждена.
